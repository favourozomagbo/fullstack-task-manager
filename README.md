# Full-Stack Task Manager

A full-stack task management application built with HTML, CSS, JavaScript, Python, and Flask.

## Features

- Add Tasks
- Edit Tasks
- Complete Tasks
- Delete Individual Tasks
- Clear All Tasks
- Search Tasks
- Filter Tasks by Category
- Due Dates
- Progress Tracking
- Dark Mode
- Flask REST API Integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Git
- GitHub

## API Endpoints

- GET /tasks
- POST /add-task
- PATCH /complete-task/<id>
- PATCH /edit-task/<id>
- DELETE /delete-task/<id>
- DELETE /clear-tasks
